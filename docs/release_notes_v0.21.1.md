# Anthro Bridge v0.21.1

- Fixed the empty **Mode** selector for Gemini 3.8 Flash in OpenRouter profiles.
- Gemini 3.8 Flash now correctly exposes **Low / Medium / High** reasoning modes in the GUI.

This is a patch release for v0.21.0. No routing, pricing, migration, or Anthro-Review protocol behavior has changed.
